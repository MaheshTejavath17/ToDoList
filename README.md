ToDoList is a simple and user-friendly task management application designed to help users organize their daily activities and manage their tasks efficiently.

The application allows users to create, update, delete, and track tasks in one place. It provides an easy way to stay organized, manage priorities, and improve daily productivity.

✨ Features
➕ Add new tasks
✏️ Edit and update existing tasks
🗑️ Delete tasks
✅ Mark tasks as completed
📋 View and manage all tasks
